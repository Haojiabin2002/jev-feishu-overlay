# 独立办公体验评审

需要独立 UX 评审时，先运行 `scripts/render_native_preview.py` 生成合成预览，再用 `scripts/prepare_blind_review.py --output ../neutral-review-kit` 导出中性任务和离线应用。导出本身不启动评审，也不证明隔离或体验完成。

仅向新的、不继承主代理历史的评审会话提供 `REVIEW_TASK.md`、界面和运行入口。不提供源码、项目 AGENTS、设计背景、配置、已知问题或主代理评价。必须使用工具明确支持的隔离方式，并让评审者记录实际收到的上下文；不能靠一句“忽略历史”冒充隔离。

评审者应实际完成任务，再回答是否可用、是否好用、无价值文案和其他优化点。只有截图时标为静态观察；不能将合成示例视为真实模型或飞书验收。禁止发送消息或申请其他账号权限。

等报告返回后逐项核实，记录接受、部分接受或不接受及理由，再进行必要修改和复测。保留 8 项模型字段与执行状态的语义，不因意见一致就认定业务成功。

工作目录约束不是 OS 沙箱。若不能验证独立上下文或无法操作 GUI，明确记录限制，不由主代理角色扮演代替。复用同一评审会话只能称复测，不再称首次盲测。

评审截图、报告、会话标识和系统路径留在本机；公开发布只提供匿名汇总。
