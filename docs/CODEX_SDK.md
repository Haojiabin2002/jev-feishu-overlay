# Codex SDK 生成后端

默认示例配置为 TypeSafe 官方 Jev 判断/排序，加 Codex SDK 生成三条候选。SDK 使用已有本机 Codex 登录，不要求另一个生成模型密钥；旧 HTTP 后端作为显式配置选项保留，不自动互相回退。

依赖安装在项目 `sdk/` 下，版本锁定于 `package-lock.json`。`codex_binary` 和 `node_binary` 必须指向本机存在且可执行的程序，客户端更新后若路径改变，doctor 与生成入口会明确报错。

每次请求使用临时工作目录和 ephemeral 会话，不恢复其他历史。正文经 stdin 传递，Jev Key 不进入 SDK 环境。请求关闭 shell、联网工具、插件、hooks、子代理和记忆；若宿主仍返回技能目录通知，只精确允许已核实的一条非致命提示。不能据此承诺所有 SDK 版本都不会附加宿主上下文。

仅接受完整 JSON 候选结果；实际工具事件、未知错误、超时或缺少最终消息都拒绝。模型由配置明确指定，失败时不换服务、不使用 demo。

运行 `node --test sdk/result.test.mjs` 验证离线协议。真实连接使用合成文本先验证，再由使用者针对明确来源批准实际会话处理。公开仓库不含任何真实输入、输出或授权。
