# 输入与执行状态

模型只返回判断和候选文本，不能控制 CLI、点击发送或选择输入目标。概率、confidence 和评分不是动作回执；复制只有在剪贴板读回一致后确认。

当前原生界面仅支持复制、修改及重新核对，**没有自动填入或发送功能**。代码中的旧 Tk / Swift 输入兼容路径不代表原生界面已支持该能力。

未来启用 Mac 填入必须另行验收：使用者明确确认，Bundle ID 白名单匹配，正确应用在前台，焦点是启用、可读、空白且可写 AXValue 的 AXTextArea。写入前复核进程、窗口、焦点及空框，只写一次，然后读取同一控件验证结果。

禁止覆盖非空草稿、向搜索框写入、按回车、发送消息或用盲目粘贴兜底。未知结果不自动重试，也不显示已成功。AX 属性不能可靠绑定 API chat_id，仍需要使用者核对会话。

消息定位同样不能干扰输入法：不监听其他应用的键盘事件，输入控件聚焦时停止扫描，不读取组合输入文本。只有鼠标导航、应用切换或明确“读取”操作才重新检查焦点。暂停、切源和迟到结果保护继续生效。

辅助功能授权不等同客户端支持读写。客户端更新、全屏、多屏或缩放后需重新验证；不支持时保留复制。
