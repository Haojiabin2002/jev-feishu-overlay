# 数据与权限边界

## 本机运行

原生悬浮窗只读取明确启用的飞书来源，并核实 CLI 用户身份。默认来源关闭、全局云端处理关闭、自动分析关闭、填入关闭、消息标注关闭。模型输出不能选择 CLI 目标、执行命令、发送消息或修改权限。

读取和模型分析分开。批准模型处理后，会话文本经过现有 `privacy.py` 清洗，再提交配置的 Jev 与生成模型服务；清洗不能保证识别所有私人或业务信息。本工具不是完全本地推理产品。

`.env` 和真实配置保持 600 权限，`.state` 为 700。分析历史数据库为 600，保存脱敏后的消息快照、模型原稿和执行状态；原消息定位 ID/原文以 hash 保存。**历史数据库仍含会话内容，不是匿名数据集。** 使用者负责保管、备份和删除本机记录。

复制会改变系统剪贴板。原生界面不提供自动发送；实验性 Mac 填入需另行验证空框、目标、写入和读回。保护边界见 [INPUT_SAFETY.md](INPUT_SAFETY.md)。

## 公开发布

本仓库从独立源码副本创建新的 Git 历史，未导入本机开发历史或以下材料：

- `.env`、真实 `config.toml` / `overlay.toml`、CLI/SDK 认证文件；
- `.state`、分析数据库、模型原始结果、真实聊天、用户身份和群 ID；
- 本机验收报告、日志、调试数据、真实屏幕截图、评审原始资料；
- 虚拟环境、Node 依赖、已编译 helper、带本机绝对路径的 `.app`、旧压缩包。

仓库图片由离屏脚本重新使用合成数据生成。上游版权人和公开仓库地址属于必要来源声明，不是私人业务信息。

发布检查包括 `.gitignore`、已跟踪文件边界检查、已知本机敏感值的精确匹配、通用密钥扫描与 Git 历史扫描。扫描通过不代表可以随意上传新日志或截图。

提交 Issue 或 PR 前，请复现为合成样本，删除令牌、账户响应、真实 ID、业务正文和本机路径。不要在公开 Issue 中报告真实密钥；发现已泄露凭据时，应在所属服务撤销并更换。

## 验证限制

现有测试不构成渗透测试、形式化隐私证明或业务准确率承诺。配额按分析次数限制，不等同金额预算。飞书客户端、CLI、模型服务更新后，应重新验证相应真实路径。
